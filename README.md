# ExpLCC

ExpLCC is a complete compiler for the Experimental Programming Language (ExpL) developed in C using Flex and Bison. The project implements the complete compilation pipeline, translating high-level ExpL programs into executable code for the Experimental String Machine (XSM).

Designed as an educational yet architecturally structured compiler, ExpLCC demonstrates the fundamental principles of compiler construction, including lexical analysis, syntax analysis, semantic analysis, abstract syntax tree construction, symbol table management, runtime memory organization, and target code generation through a modular multi-stage architecture.

## Highlights

- Lexical analysis using Flex
- LR parsing using Bison
- Syntax-directed translation
- Abstract Syntax Tree (AST) construction
- Semantic analysis and type checking
- Global and local symbol table management
- Runtime stack and memory management
- Register allocation
- Function call and activation record management
- Target code generation for the XSM virtual machine
- Modular compiler architecture

## Architecture Overview

ExpLCC follows a multi-stage compiler architecture where each phase transforms the source program into progressively lower-level representations.

```
ExpL Source Program
        │
        ▼
Lexical Analysis
        │
        ▼
Syntax Analysis
        │
        ▼
Semantic Analysis
        │
        ▼
Abstract Syntax Tree
        │
        ▼
Code Generation
        │
        ▼
XSM Assembly
        │
        ▼
Executable Program
```

## Core Components

### Lexical Analyzer

Converts the source program into a stream of tokens using deterministic finite automata generated by Flex.

### Parser

Performs LR parsing using Bison, validates program syntax, and constructs the Abstract Syntax Tree through syntax-directed translation.

### Semantic Analyzer

Verifies program correctness by performing scope resolution, symbol lookup, and type checking.

### Abstract Syntax Tree

Represents the hierarchical structure of the source program and serves as the intermediate representation for subsequent compilation stages.

### Symbol Table Manager

Maintains global and local symbol tables for variables, functions, user-defined types, and compile-time metadata.

### Runtime Manager

Implements stack frame organization, memory allocation, register management, and runtime support required during program execution.

### Code Generator

Traverses the AST to generate XSM assembly while preserving the semantics of the source program.
